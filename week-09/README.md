# Week 9 — Atomic Red Team

## 1. Introduction

Atomic Red Team is an open-source library of small security tests mapped to MITRE ATT&CK techniques.

These tests allow security analysts to simulate selected adversary behaviors and evaluate whether security monitoring tools can observe them.

## 2. Objectives

- Understand the Atomic Red Team framework.
- Select specific Atomic Tests.
- Execute selected tests in an authorized Windows lab.
- Collect related Windows events using Sysmon and Elastic Agent.
- Analyze test results in Elastic Discover.
- Map observed behavior to MITRE ATT&CK.

## 3. Selected Atomic Tests

| Test | Technique | Description |
|---|---|---|
| T1059.001 — Test #17 | PowerShell | PowerShell Command Execution |
| T1059.003 — Test #2 | Windows Command Shell | Writes text to a file and displays it |

Both techniques belong to the MITRE ATT&CK Execution tactic.

## 4. Environment

- Operating System: Windows
- Host: HOME-PC
- Monitoring: Microsoft Sysmon
- Data Collection: Elastic Agent
- SIEM: Elastic Cloud
- Analysis: Elastic Discover and KQL
- Testing Framework: Atomic Red Team

## 5. Methodology

1. Review the Atomic Test definitions.
2. Check test prerequisites.
3. Execute selected benign tests.
4. Collect process creation events using Sysmon Event ID 1.
5. Search for the relevant process executions in Elastic Discover.
6. Analyze event timestamps, command lines, and parent processes.
7. Record results and screenshots.
8. Clean up temporary test artifacts.

## 6. Detection Objective

Determine whether Elastic SIEM can identify the process execution activity generated by the selected Atomic Tests.

## 7. Expected Results

The expected telemetry includes PowerShell and CMD process creation events.

The CMD test may also generate a file creation event if the corresponding Sysmon logging is enabled.

## 8. Conclusion

Atomic Red Team provides repeatable tests for evaluating defensive visibility.

This exercise connects MITRE ATT&CK, adversary emulation, Sysmon process monitoring, and Elastic threat hunting.
